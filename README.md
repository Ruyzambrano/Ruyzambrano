I'm a Data Coach at [Multiverse](https://www.multiverse.io/), where I help apprentices build real skills in data engineering, cloud and AI. ## Things I've built

* **[Slate Focus](https://github.com/Ruyzambrano/slate-focus)** is a Chrome extension that adds a mouse-following reading ruler and a more readable layout to any page. [Live on the Chrome Web Store](https://chromewebstore.google.com/detail/beelcoomgjoeichjghepcggknldobdhf).
* **[llm_catalogue](https://github.com/Ruyzambrano/llm_catalogue)** is a zero-dependency Python package with model names, pricing and free-tier metadata for OpenAI, Anthropic and Google Gemini, so you don't have to keep re-checking which models are actually free this week. [`pip install llm-catalogue`](https://pypi.org/project/llm-catalogue/)
* **[Complexifier](https://github.com/Ruyzambrano/complexifier)** is a Python library that takes clean data and deliberately makes it worse (typos, nulls, outliers, duplicates), built for teaching data cleaning. [`pip install complexifier`](https://pypi.org/project/complexifier/)
* **[The Slate Job Curator](https://github.com/Ruyzambrano/the-slate-job-curator)** turns a CV into a curated dossier of roles, with real gap analysis and seniority auditing instead of keyword matching, plus a grounded cover letter for the ones worth applying to. [Try it live](https://theslatejobcurator.streamlit.app/)

More on my [GitHub profile](https://github.com/Ruyzambrano?tab=repositories).

## Take a look how I integrate tech into performance!

### [*This has been coming a long time, now*](https://www.youtube.com/watch?v=R-Hg4UPXeY0&ab_channel=RuyZambrano)

This performance uses a manipulated video of the dancer to create a monstrous digital double. Based on the research about Victorian Gothic horror, the performance integrates themes of the unknown and uncanny through technological ambiguity such as dim lights, projection, sound and using the dancer's skin as a projection surface.

### [*We Found It With Each Other*](https://www.youtube.com/watch?v=uVFoqOnRDgM&ab_channel=RuyZambrano)

As part of an undergraduate thesis, this performance uses tech to segment it into chunks. As the performance changes, tech is used to keep track of time, cue light and sound changes as well as add stunning visuals to highlight movement.
